# FnMusic 开源策略

> 本文档说明本项目的开源目标、许可证、维护与协作方式。欢迎社区参与。

## 1. 定位与目标

FnMusic 由 **XDORG 团队自主研发**，是一个面向飞牛 NAS（FNOS）的音乐客户端（Android 15+），定位是：

- 提供一个**开箱即用、体验流畅**的 NAS 音乐播放方案；
- 保持**单一代码库、简单架构**，让使用者与贡献者都能快速上手；
- 以**开放、透明、可维护**的方式长期演进，而不是一次性发布。

开源不是为了「多一个仓库」，而是希望让有同样需求的用户免于重复造轮子，并共同打磨产品。

## 2. 许可证：Apache-2.0

本项目采用 **Apache License 2.0**（见仓库根目录 [LICENSE](../LICENSE)）。

- 允许自由使用、修改、分发，包括商业用途与闭源衍生；
- 包含**专利授权**条款，对贡献者与使用者更友好、边界更清晰；
- 分发或修改时需保留版权声明与许可证副本（详见 LICENSE 第 4 节）。

使用者可以放心地基于本代码二次开发，但应保留原始版权与许可声明。

## 3. 维护模型

- **维护者**：项目由个人维护者驱动，按可用时间持续推进；
- **响应**：Issues / PR 尽量在数日内回复，里程碑内排期；
- **质量门槛**：每个合并请求必须通过 `flutter analyze`（0 issues）与 `flutter test`（全绿），保证代码可回归验证；
- **功能取舍**：优先「真实可用、真机验证」的完整闭环，而非堆砌半成品。

## 4. 版本与发布策略

- 采用语义化版本（`主版本.次版本.修订号`），当前稳定版本 **v1.0.0**；
- 每次正式发布在 GitHub Releases 附带构建产物（APK），并更新发行说明；
- 主分支（`main`）保持可构建、可运行状态；特性开发走普通提交，重大改动通过 PR 评审合并；
- 破坏性变更会说明迁移方式，并在大版本中集中发布。

## 5. 如何参与贡献

### 报告问题 / 提需求

- 在 [Issues](https://github.com/XDORG-N1/FnMusic/issues) 新建 issue；
- 说明**复现步骤**、设备与系统版本、FNOS 版本、日志/截图，能显著加快定位；
- 功能建议请描述使用场景与预期行为。

### 提交代码（PR）

1. Fork 仓库并创建特性分支；
2. 遵循现有代码风格与目录结构，补全对应测试；
3. 本地通过 `flutter analyze` 与 `flutter test`；
4. 提交 PR，描述改动动机与影响面；若关联 issue，请注明编号。

### 贡献约定

- 代码注释与 UI 文案使用简体中文，标识符使用英文；
- 不引入未经授权的第三方代码或素材；贡献即表示同意以 Apache-2.0 授权；
- 涉及安全问题的提交，请优先私信维护者而非公开。

## 6. 行为准则（简要）

- 对事不对人，保持友善与建设性；
- 允许不同技术观点，以证据与可验证性为准；
- 对新手友好，乐于解释而不是评判。

## 7. 社区与反馈渠道

- **Issues**：问题报告、功能请求
- **PR**：代码贡献
- **GitHub Releases**：版本发布与下载
- 仓库主页：<https://github.com/XDORG-N1/FnMusic>

## 8. 路线图方向

按社区反馈优先级推进，候选方向包括：

- 更多系统级集成（状态栏歌词、桌面部件、深度系统联动）
- 播放体验增强（均衡器、无损格式更优支持）
- 跨端支持（更多 Android 版本 / 形态适配）
- 数据与体验优化（更大资料库的浏览性能、更细的听歌统计）

实际排期以 Issues 讨论与里程碑为准，欢迎参与讨论。
